# Residence 3D walkthrough

Interactive 3D walkthrough of a two-storey Kerala home, built to scale from the floor plan with Three.js.

**Live:** https://cridorainfo.github.io/home-tour/

- Walk with W A S D + mouse, Tab for the dollhouse view
- Day / Dusk lighting (T), three interior styles (1, 2, 3)
- Works in Chrome or Edge on a desktop; the first load takes about 20 seconds
